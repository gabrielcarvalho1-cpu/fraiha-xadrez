# FRAIHA Steam release plan — PREPARADO

Pesquisa primária 2026-10-06 UTC. Nenhuma conta/AppID/depot criado, SDK instalado, compra, login SteamCMD, upload ou publicação. Steam deve iniciar o **jogo diretamente** e gerenciar suas atualizações; não distribuir launcher/updater site dentro do depot.

Pré-requisitos humanos: titular legal, conta Steamworks aprovada, AppID próprio e direitos de distribuição/arte/engine. Onboarding inclui dados legais/bancários/fiscais, taxa por produto e revisão loja/build; fonte consultada atualmente informa espera 21 dias após pagamento e Coming Soon pelo menos duas semanas. Não usar prazo histórico de 30 dias sem revalidar. Nenhum pagamento feito. [Onboarding oficial](https://partner.steamgames.com/doc/gettingstarted/onboarding).

Plano: export Windows x86_64 homologado com `platform=windows_steam`, game_version/build_number central; protocol/rules iguais ao site/Web/mobile compatíveis. AppID e DepotID somente atribuídos pela Valve; não inventar números nem reutilizar Spacewar. Preparar ContentBuilder com diretório de conteúdo completo, scripts app/depot VDF, logs/cache de build externos e BuildID Steam registrado no release ledger junto do SHA fonte/hash artefato. SteamPipe é proprietário da entrega em deltas; branches internas/dev/beta antes do default. Configurar launch option relativa `FRAIHA.exe`, sem launcher site, sem argumentos auth. [SteamPipe oficial](https://partner.steamgames.com/doc/sdk/uploading).

Depot Windows contém todos os arquivos requeridos pela export, inclusive DLL/config/engine/licenças quando aplicável; ZIP EXE+PCK do DEV site não demonstra completude. Pacote comercial/developer-comp concede acesso aos depots e precisa incluir os IDs corretos; store package não é versão técnica. [Packages](https://partner.steamgames.com/doc/store/application/packages). Avaliar Common Redistributables só para dependências efetivas da export; não instalar SDK/runtime desnecessário e não confundir .NET do launcher DEV com necessidade do jogo GDScript. [Redistributables](https://partner.steamgames.com/doc/features/common_redist).

Store readiness: nome/publisher legais, descrição real, screenshots do jogo efetivo, cápsulas/ícones aprovados, idiomas, requisitos mínimos medidos, classificação/conteúdo/privacy/support e escolha de pacote/preço por humano. Declarar necessidade de conta FRAIHA e rede sem alegar Steam auth. Nenhuma página publicada ou preço definido. Future SteamID linkage é opt-in com verificação de propriedade na conta FRAIHA, fora deste escopo.

QA futuro: instalação limpa via Steam beta, launch direto, integridade depot, upgrade via Steam, branch switch autorizado, save/userdata preservados, offline/menu comportamento documentado, conexão mesmo backend com Web/site/Android/iOS. Testar entitlement no servidor em tarefa própria; nunca considerar branch/platform identificador confiável. Nenhuma combinação crossplay executada aqui.

Excluídos explicitamente: achievements, Steam Cloud, overlay, Steam auth, matchmaking Steam, inventário, microtransactions e SteamID linkage implementada. Backend/matchmaking continuam FRAIHA compartilhados. Release humana segue SOURCE → TESTS → VERSION → BUILD → PACKAGE → HASH → MANIFEST/ledger → QA → PUBLISH, com aprovação própria antes do último passo. Revise documentação/estado principal novamente antes de integrar; não foi publicado nada.
